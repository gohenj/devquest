# DevQuest

Painel de estudos organizado em missões, desenvolvido com
React e TypeScript.

## Funcionalidades

- Cadastro de missões com nome e tecnologia.
- Validação de campos vazios ou contendo apenas espaços.
- Status: Vou estudar, Estudando e Concluído.
- Busca pelo nome da missão.
- Filtro por tecnologia combinado com a busca.
- Painel com contadores e percentual de conclusão.
- Persistência das missões no localStorage.
- Layout responsivo e controles acessíveis por teclado.

## Tecnologias

- React
- TypeScript
- CSS
- Vite
- ESLint

## Executar localmente

É necessário ter Node.js e npm instalados.

Após clonar o repositório:

npm ci
npm run dev

Abra o endereço informado pelo terminal.

## Verificações

npm run build
npm run lint

Para visualizar o build de produção:

npm run preview

## Armazenamento

Os dados ficam salvos no navegador e no endereço em que o
aplicativo é acessado.

Não há login, servidor ou sincronização entre dispositivos.
Limpar os dados do site no navegador remove as missões salvas.

## Aprendizados

Projeto desenvolvido para praticar componentes reutilizáveis,
props, estado, eventos, tipagem, filtros e persistência local.

O desenvolvimento também utiliza branches, commits e
Pull Requests no GitHub.
